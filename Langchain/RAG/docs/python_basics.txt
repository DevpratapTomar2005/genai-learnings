----------------------------------------------------------------
1. VARIABLES & DATA TYPES
----------------------------------------------------------------
  EXPLANATION:
  A variable is a named container used to store data in memory.
  You don't need to declare the type — Python figures it out
  automatically (this is called dynamic typing). Every value in
  Python has a data type that determines what operations can be
  performed on it.

  Common data types:
  - int   : Whole numbers (e.g., 5, -10, 100)
  - float : Decimal numbers (e.g., 3.14, -0.5)
  - str   : Text (e.g., "hello", 'world')
  - bool  : True or False values
  - None  : Represents the absence of a value

# Integer
age = 25

# Float
price = 19.99

# String
name = "Alice"

# Boolean
is_active = True

# NoneType
value = None

# Check type
print(type(age))       # <class 'int'>


----------------------------------------------------------------
2. STRINGS
----------------------------------------------------------------
  EXPLANATION:
  A string is a sequence of characters enclosed in single (' ')
  or double (" ") quotes. Strings are one of the most commonly
  used data types in Python. They are immutable — once created,
  their content cannot be changed directly.

  Key concepts:
  - Indexing  : Access individual characters using [index]
  - Slicing   : Extract a portion using [start:end]
  - Methods   : Built-in functions like .upper(), .lower(),
                .replace(), .strip(), .split(), etc.
  - f-strings : A clean way to embed variables inside strings
                using the f"...{variable}..." syntax

greeting = "Hello, World!"

# String methods
print(greeting.upper())          # HELLO, WORLD!
print(greeting.lower())          # hello, world!
print(greeting.replace("Hello", "Hi"))  # Hi, World!
print(len(greeting))             # 13

# String formatting (f-string)
name = "Alice"
age = 25
print(f"My name is {name} and I am {age} years old.")

# String slicing
text = "Python"
print(text[0])      # P      -> first character
print(text[-1])     # n      -> last character
print(text[0:3])    # Pyt    -> characters from index 0 to 2


----------------------------------------------------------------
3. NUMBERS & MATH OPERATIONS
----------------------------------------------------------------
  EXPLANATION:
  Python supports two main numeric types: integers (int) and
  floating-point numbers (float). You can perform all standard
  arithmetic operations directly.

  Key operators:
  - +   : Addition
  - -   : Subtraction
  - *   : Multiplication
  - /   : Division (always returns a float)
  - //  : Floor division (rounds down to nearest whole number)
  - %   : Modulus (returns the remainder of division)
  - **  : Exponentiation (power)

  Python also follows standard order of operations (PEMDAS/BODMAS).
  Use parentheses () to control evaluation order.

a = 10
b = 3

print(a + b)    # Addition       -> 13
print(a - b)    # Subtraction    -> 7
print(a * b)    # Multiplication -> 30
print(a / b)    # Division       -> 3.333...
print(a // b)   # Floor Division -> 3
print(a % b)    # Modulus        -> 1
print(a ** b)   # Exponent       -> 1000


----------------------------------------------------------------
4. LISTS
----------------------------------------------------------------
  EXPLANATION:
  A list is an ordered, mutable (changeable) collection of items.
  Lists can hold any mix of data types — numbers, strings, other
  lists, etc. They are defined using square brackets [].

  Key features:
  - Ordered    : Items have a fixed position (index)
  - Mutable    : You can add, remove, or change items
  - Zero-based : First item is at index [0]
  - Duplicates : Lists allow duplicate values

  Lists are one of the most versatile and widely-used data
  structures in Python. Use them when you need an ordered
  collection that you'll modify over time.

fruits = ["apple", "banana", "cherry"]

# Access elements
print(fruits[0])         # apple  -> first item
print(fruits[-1])        # cherry -> last item

# Modify the list
fruits.append("mango")   # Add to end
fruits.remove("banana")  # Remove by value
fruits.insert(1, "kiwi") # Insert at a specific index

# Useful list methods
print(len(fruits))       # Number of items
print(sorted(fruits))    # Returns a new sorted list
fruits.sort()            # Sorts the list in-place
fruits.reverse()         # Reverses the list in-place

# List slicing -- extract a portion of the list
numbers = [1, 2, 3, 4, 5]
print(numbers[1:4])      # [2, 3, 4]


----------------------------------------------------------------
5. TUPLES
----------------------------------------------------------------
  EXPLANATION:
  A tuple is similar to a list, but it is immutable — once
  created, its values cannot be changed. Tuples are defined
  using parentheses ().

  When to use tuples over lists:
  - When the data should not be modified (e.g., coordinates,
    RGB color values, database records)
  - Tuples are slightly faster than lists
  - They can be used as dictionary keys (lists cannot)

  Since tuples are immutable, they don't have methods like
  .append() or .remove(). You can still access elements by
  index and use len() on them.

# Tuples are immutable (cannot be changed after creation)
coordinates = (10.5, 20.3)
rgb = (255, 128, 0)

print(coordinates[0])   # 10.5
print(len(rgb))         # 3


----------------------------------------------------------------
6. DICTIONARIES
----------------------------------------------------------------
  EXPLANATION:
  A dictionary is an unordered collection of key-value pairs.
  Each key is unique and maps to a value. Dictionaries are
  defined using curly braces {} with "key": value syntax.

  Key features:
  - Fast lookups : Access values instantly by key
  - Mutable      : Add, update, or delete key-value pairs
  - Keys         : Must be immutable (strings, numbers, tuples)
  - Values       : Can be any data type, including lists or
                   even other dictionaries

  Dictionaries are ideal for storing structured data, like
  user profiles, configuration settings, or JSON-like data.

person = {
    "name": "Alice",
    "age": 25,
    "city": "New York"
}

# Access values
print(person["name"])           # Alice
print(person.get("age"))        # 25  (safer -- won't crash if key missing)

# Modify the dictionary
person["email"] = "alice@example.com"  # Add new key
person["age"] = 26                     # Update existing value
del person["city"]                     # Delete a key

# Iterate over all key-value pairs
for key, value in person.items():
    print(f"{key}: {value}")


----------------------------------------------------------------
7. SETS
----------------------------------------------------------------
  EXPLANATION:
  A set is an unordered collection of unique values. Sets are
  defined using curly braces {}, but unlike dictionaries, they
  contain only values (no key-value pairs).

  Key features:
  - No duplicates : Automatically removes repeated values
  - Unordered     : No index-based access
  - Mutable       : Can add or remove elements

  Sets are great for removing duplicates from a list, and for
  performing mathematical set operations like union,
  intersection, and difference.

# Sets automatically remove duplicates
colors = {"red", "blue", "green", "blue"}
print(colors)   # {'red', 'blue', 'green'} -- duplicate removed

colors.add("yellow")     # Add a new element
colors.discard("red")    # Remove (no error if not found)

# Set operations -- useful for comparing two collections
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a | b)   # Union        -> {1, 2, 3, 4, 5, 6}  (all elements)
print(a & b)   # Intersection -> {3, 4}               (common elements)
print(a - b)   # Difference   -> {1, 2}               (in a but not b)

8. CONDITIONALS (if / elif / else)
----------------------------------------------------------------
  EXPLANATION:
  Conditionals allow your program to make decisions — executing
  different blocks of code based on whether a condition is True
  or False. Python uses if, elif (else if), and else for this.

  How it works:
  - Python evaluates the condition after 'if'
  - If True  -> runs that block and skips the rest
  - If False -> checks the next 'elif' condition
  - If none match -> runs the 'else' block (optional)

  Comparison operators used in conditions:
  ==  (equal), !=  (not equal), >  (greater than),
  <   (less than), >= (greater or equal), <= (less or equal)

  Logical operators: and, or, not

score = 75

if score >= 90:
    print("Grade: A")
elif score >= 75:
    print("Grade: B")
elif score >= 60:
    print("Grade: C")
else:
    print("Grade: F")

# Ternary expression -- a compact one-liner conditional
status = "Pass" if score >= 60 else "Fail"
print(status)   # Pass

9. LOOPS
----------------------------------------------------------------
  EXPLANATION:
  Loops let you repeat a block of code multiple times, saving
  you from writing the same code over and over. Python has two
  types of loops:

  - for loop   : Iterates over a sequence (list, range, string,
                 dictionary, etc.) a fixed number of times
  - while loop : Repeats as long as a condition remains True

  Loop control keywords:
  - break    : Immediately exits the loop
  - continue : Skips the current iteration and moves to the next
  - pass     : Does nothing (used as a placeholder)

  List comprehension is a Pythonic shorthand for creating a
  new list by applying an expression to each item in a sequence.

# For loop using range
for i in range(5):
    print(i)       # Prints 0, 1, 2, 3, 4

# For loop over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# While loop -- runs until condition becomes False
count = 0
while count < 5:
    print(count)
    count += 1

# Loop control -- break and continue
for i in range(10):
    if i == 3:
        continue    # Skip number 3
    if i == 7:
        break       # Stop loop at 7
    print(i)

# List comprehension -- concise way to build a list
squares = [x**2 for x in range(1, 6)]
# Result: [1, 4, 9, 16, 25]

10. FUNCTIONS
----------------------------------------------------------------
  EXPLANATION:
  A function is a reusable block of code that performs a
  specific task. Instead of repeating code, you define it once
  and call it whenever needed. Functions make your code modular,
  readable, and easier to maintain.

  Key concepts:
  - def        : Keyword used to define a function
  - Parameters : Variables listed in the function definition
  - Arguments  : Actual values passed when calling the function
  - return     : Sends a value back to the caller
  - Default parameters : Used when no argument is provided
  - *args      : Accepts any number of positional arguments
  - **kwargs   : Accepts any number of keyword arguments

def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))    # Hello, Alice!

# Default parameter -- used when argument is not provided
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Bob"))             # Hello, Bob!
print(greet("Bob", "Hi"))       # Hi, Bob!

# Returning multiple values as a tuple
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([3, 1, 7, 2])
print(low, high)   # 1 7

# *args -- variable number of positional arguments
def total(*args):
    return sum(args)

print(total(1, 2, 3, 4))   # 10

# **kwargs -- variable number of keyword arguments
def display(**kwargs):
    for key, value in kwargs.items():
        print(f"{key} = {value}")

display(name="Alice", age=25)

11. CLASSES & OBJECTS
----------------------------------------------------------------
  EXPLANATION:
  Python supports Object-Oriented Programming (OOP). A class
  is a blueprint for creating objects. An object is an instance
  of a class that holds data (attributes) and behavior (methods).

  Key OOP concepts:
  - Class       : Template/blueprint defining structure & behavior
  - Object      : An instance created from a class
  - __init__    : Constructor — runs automatically when an object
                  is created; used to set initial attributes
  - self        : Refers to the current object instance
  - Method      : A function defined inside a class
  - Inheritance : A child class inherits attributes and methods
                  from a parent class, allowing code reuse
  - super()     : Calls the parent class's constructor or method

class Animal:
    # Constructor -- sets up the object with initial data
    def __init__(self, name, species):
        self.name = name
        self.species = species

    # Method -- defines behavior of the object
    def speak(self):
        return f"{self.name} makes a sound."

    # __str__ -- controls what print() shows for this object
    def __str__(self):
        return f"{self.name} ({self.species})"


# Inheritance -- Dog reuses Animal's structure and adds its own
class Dog(Animal):
    def __init__(self, name):
        super().__init__(name, "Canine")  # Call parent constructor

    # Override the speak() method
    def speak(self):
        return f"{self.name} says: Woof!"


dog = Dog("Buddy")
print(dog.speak())     # Buddy says: Woof!
print(str(dog))        # Buddy (Canine)

12. ERROR HANDLING
----------------------------------------------------------------
  EXPLANATION:
  Errors (exceptions) occur when something goes wrong at
  runtime — like dividing by zero or accessing a missing file.
  Instead of crashing, Python lets you catch and handle these
  errors gracefully using try/except blocks.

  Structure:
  - try     : Code that might cause an error
  - except  : Runs if a specific error occurs
  - else    : Runs only if NO error occurred in try
  - finally : Always runs, whether an error happened or not
              (great for cleanup tasks like closing files)
  - raise   : Manually trigger an exception with a message

  Common exceptions:
  - ZeroDivisionError : Division by zero
  - ValueError        : Invalid value for a function
  - TypeError         : Wrong type used in an operation
  - FileNotFoundError : File does not exist
  - KeyError          : Key not found in a dictionary
  - IndexError        : Index out of range in a list

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero!")
except ValueError as e:
    print(f"Value error: {e}")
else:
    print("No error occurred.")   # Only runs if try succeeded
finally:
    print("This always runs.")    # Cleanup code goes here

# Raise a custom exception manually
def check_age(age):
    if age < 0:
        raise ValueError("Age cannot be negative.")
    return age

13. FILE HANDLING
----------------------------------------------------------------
  EXPLANATION:
  Python makes it easy to read from and write to files on your
  system. The built-in open() function is used to open a file,
  and the 'with' statement ensures the file is properly closed
  after use (even if an error occurs).

  File modes:
  - "r"  : Read (default) -- file must exist
  - "w"  : Write -- creates file or overwrites existing content
  - "a"  : Append -- adds to existing content without deleting
  - "x"  : Create -- fails if file already exists
  - "rb" / "wb" : Read/write in binary mode (for images, etc.)

  Best practice: Always use 'with open(...)' — it automatically
  handles closing the file, even if an error occurs.

# Write to a file (creates it if it doesn't exist)
with open("output.txt", "w") as f:
    f.write("Hello, File!\n")
    f.write("Second line.\n")

# Read entire file content at once
with open("output.txt", "r") as f:
    content = f.read()
    print(content)

# Read the file line by line (efficient for large files)
with open("output.txt", "r") as f:
    for line in f:
        print(line.strip())   # .strip() removes trailing newline

# Append new content without overwriting existing content
with open("output.txt", "a") as f:
    f.write("Appended line.\n")

14. COMMON BUILT-IN FUNCTIONS
----------------------------------------------------------------
  EXPLANATION:
  Python comes with many built-in functions that are always
  available — no import needed. These cover common tasks like
  type conversion, math operations, sequence manipulation,
  and iteration utilities.

  These functions save you from writing repetitive code and
  are optimized for performance. Learning these well will
  make your Python code cleaner and more efficient.

  Key categories:
  - Type conversion : int(), float(), str(), bool(), list()
  - Sequence tools  : len(), range(), sorted(), reversed(),
                      enumerate(), zip(), map(), filter()
  - Math helpers    : abs(), max(), min(), sum(), round()
  - Inspection      : type(), print(), input(), id()

print(len([1, 2, 3]))        # 3       -- number of items
print(range(1, 6))           # range(1, 6)
print(list(range(1, 6)))     # [1, 2, 3, 4, 5]
print(type(3.14))            # <class 'float'>
print(int("42"))             # 42      -- string to integer
print(str(100))              # '100'   -- integer to string
print(float("3.14"))         # 3.14    -- string to float
print(abs(-7))               # 7       -- absolute value
print(max(3, 1, 7, 2))       # 7       -- largest value
print(min(3, 1, 7, 2))       # 1       -- smallest value
print(sum([1, 2, 3, 4]))     # 10      -- total sum
print(round(3.14159, 2))     # 3.14    -- rounded to 2 decimals
print(sorted([3,1,2]))       # [1,2,3] -- returns sorted copy
print(reversed([1,2,3]))     # iterator (use list() to see)
print(enumerate(["a","b"]))  # (0,'a'), (1,'b') -- index + value
print(zip([1,2], ["a","b"])) # (1,'a'), (2,'b') -- pairs items
print(map(str, [1,2,3]))     # applies str() to each item
print(filter(None, [0,1,2])) # removes falsy values -> [1, 2]

15. MODULES & IMPORTS
----------------------------------------------------------------
  EXPLANATION:
  A module is a file containing Python code (functions,
  classes, variables) that you can reuse in other programs.
  Python has a large standard library of built-in modules, and
  you can also install third-party packages using pip.

  How to use modules:
  - import module         : Imports the whole module
  - from module import X  : Imports only what you need
  - import module as m    : Uses a shorter alias name

  Popular standard library modules:
  - math     : Mathematical functions and constants
  - random   : Random number generation
  - os       : Operating system interaction (files, paths)
  - datetime : Working with dates and times
  - sys      : System-level operations
  - json     : Parse and generate JSON data
  - re       : Regular expressions for pattern matching

import math
import random
import os
import datetime

# math -- mathematical operations
print(math.sqrt(16))       # 4.0    -- square root
print(math.pi)             # 3.14159... -- pi constant
print(math.floor(3.7))     # 3      -- round down
print(math.ceil(3.2))      # 4      -- round up

# random -- generate random values
print(random.randint(1, 10))          # Random integer between 1 and 10
print(random.choice(["a", "b", "c"])) # Random item from a list
random.shuffle([1, 2, 3])             # Shuffle a list in place

# os -- interact with the operating system
print(os.getcwd())         # Print current working directory
print(os.listdir("."))     # List all files in current directory

# datetime -- work with dates and times
now = datetime.datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))  # Formatted date/time

# Import specific items from a module (more efficient)
from math import sqrt, pi
from random import randint
